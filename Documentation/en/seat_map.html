Seat map

The seat map holds the tables of the hall and their position. When the Use table list option of the Settings is on, in the order entry window the table is chosen with a click on the map instead of typing it.

The tables

  • Table code: the name of the table, the one written in the order. Two tables can not have the same code.
  • Row and Column: the position of the table in the map. Two tables can not take the same position.
  • Text color and Background color: the colors of the table button.
  • Unavailable: the table appears in the map but can not be chosen, for example because it is reserved.
  • Obsolete: the table is no longer used and does not appear in the map.

Generating the tables

Generate table numbers creates a whole block of tables at once:

  • Start row, Rows and Columns: where the block starts and how big it is.
  • Table code: the code is made of Prefix, row number and column number (row + column) or the other way round (column + row), and Suffix. Row padding and Column padding add zeros in front of the numbers, for example 01 instead of 1.
  • Button color: the colors of the generated tables. With Change background color on change row/column every row, or column, takes one of the ten colored buttons, which can be changed with a click.

The generated tables are added to the existing ones and must be saved. Delete All deletes all the tables of the company.

Geometry and preview

Base geometry sets rows, columns and spacing of the map in the order entry window; Minimum size is the size of the empty cells in the preview. Preview shows the map as it will look and saves the geometry; Edit goes back to the table list.
