Companies

A company is a set of data kept apart from all the others: items, events, orders, settings. Several companies are used for example to keep different festivals apart, or a test festival; every user works in one company at a time, and changes it with Change company.

  • Code and Description: the description is required.
  • System company: the base company of the program, which can not be changed nor deleted.
  • User / Profiles / Menu / Toolbar: the users that can work in the company and, for each one, the profile with its rights, the menu and the toolbar.
  • Company image: the background of the main window when there is no event image, and it can be used in the reports.

A new company is created with a code, a description and the profile, menu and toolbar the current user will access it with. To fill it starting from another company there is the Copy tool.
