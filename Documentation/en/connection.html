Connections

Active connections

The users connected now: who, from which computer, since when, in which company. Kill client closes, after a confirm, the chosen connection, for example of a program left open on a computer that was turned off; the own connection can not be closed.

Connection history

The list of the past logins. To keep it from growing too much:

  • Delete older records: deletes the logins older than a number of days.
  • Delete all records: empties the history.
  • Automatic deletion after ... days and Update setting: the automatic cleaning.
