ESC/POS printers

ESC/POS printers are the thermal receipt printers, that the program drives directly, without the driver of the operating system. They are connected by USB or by network; this form describes each printer, which is then chosen in the Order print settings form.

  • Computer name: the computer the USB printer is connected to; the current one is proposed. A network printer does not depend on the computer.
  • Printer name: the name used to choose the printer in the print settings. It can not be the same as the one of another printer.
  • Printer type: USB or Network.

For a network printer:

  • Host address: the IP address of the printer.
  • Port: usually 9100.
  • Connection timeout: how many seconds to wait for the printer before giving an error.

For a USB printer:

  • Id Vendor and Id Product: the two numbers that identify the printer model; they are in the manual or in the system information about USB devices.
  • USB timeout, Input endpoint and Output endpoint: parameters of the USB communication; the proposed values suit most printers.

Deleting a printer does not delete the print settings that use it: they stay with no printer, and that copy goes to the preview until another printer is chosen.
