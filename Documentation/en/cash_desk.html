Cash desk

This form gives a name to the cash desks. The name is normally printed on the documents, so that it is possible to know which cash desk issued them.

The form sets three values:

  • Computer name is the name of the computer where the program runs; it is proposed automatically when a new row is added. A computer can have one cash desk only.
  • Cash desk description
  • Note is an optional field for a note about the cash desk

A description of the cash desk is optional, the program works correctly without it too.
