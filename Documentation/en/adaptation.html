Customizations

Customizations are the layouts saved by the users: columns of the grids, sortings and filters, report settings. This window exports them to files, imports them and deletes them, for example to move them to another database.

  • Adaptation type: ItemView (column layouts of grids and trees), SortFilter (sortings and filters) and Report (customizations of the print window).
  • Export: saves to a folder the customizations of the chosen type; an existing file is overwritten only after a confirm.
  • Import: loads the customizations from a file. The import is done all together: when it fails, nothing is loaded.
  • Clear: deletes, after a confirm, all the customizations of the chosen type.
