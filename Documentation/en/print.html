Print

The print window is the same for all the reports: archives, orders, statistics.

Report

In Print method / Report class / Report choose the report among the ones of the class: for example the item reports or the different statistics. Every report has its own Parameters, Filters and sorting.

Printing

  • Print preview: shows the report on screen, from where it can be printed too.
  • Print: opens the printer choice of the operating system.
  • Print direct: prints at once on the printer set in Direct print to.
  • Export PDF: creates a PDF file in the chosen Directory, with the File name, PDF version and Resolution set; with Open PDF file after creation the file opens at once.

Customizations

The Customize tab saves parameters, filters and sorting used often, with a name:

  • New adaptation and Create: creates an empty customization; then choose it, set parameters, filters and sorting and save it with Update.
  • Delete: deletes the current customization.
  • Set as user default and Set as class default: the customization that opens by itself, for the user or for everybody.

The tab is available only to the users that can edit reports.
