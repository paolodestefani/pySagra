Menus

The menu of the main window, organized as a tree: every entry can be an action, a submenu or a separator. Every user gets a menu for each company.

  • Code and Description of the menu.
  • System menu: a menu of the program, which can not be changed nor deleted. To change it, make a copy with Duplicate.
  • The tree of the entries: for each entry the code, the shown description, the sorting, the type (action, menu or separator) and the action. The buttons add an entry under the chosen one or after it, or remove it.

A submenu can be used by several menus, and a change applies to all the ones that use it. The submenus used by a system menu too are read only: to change them, create a new one with another code.

The context menu of the tree saves width, position and visibility of the columns.
