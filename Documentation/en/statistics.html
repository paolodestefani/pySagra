Statistics

Two functions to analyze the orders.

Print statistics

It opens the print window with the statistic reports, for example sales and consumption: choose the report, set filters and parameters and print, see the Print page.

Export statistic data

It writes the orders to two CSV files, to open with a spreadsheet:

  • Headers file: the file with one row for each order (date, time, day part, cash desk, delivery, table, customer, covers, amounts).
  • Details file: the file with one row for each ordered item (department, item, variants, quantity, price, amount).
  • From event and To event: the events to export, or Include ALL events.

Fields are separated by semicolons and numbers use the decimal separator of the user language. When something goes wrong, for example a file that can not be written, the window stays open to correct and try again.
