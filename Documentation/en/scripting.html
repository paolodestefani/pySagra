Python scripting

Small Python programs that change the behavior of the forms without changing the program: for example one more check when an item is saved.

  • Class: the form or window the script applies to.
  • Method: the operation of the form, for example save, delete or new; __init__ is the opening of the form.
  • Trigger: Before, After or Instead of that operation. Opening scripts (__init__) run only with After.
  • Company: the company the script is valid in.
  • Active: only active scripts run. It can be changed with no write right too, to turn off a script that gives problems.
  • System: a script of the program, which can not be changed nor deleted.
  • Python script and Note: the code and a description of it. In the code self is the form and session the session data.

Scripts are saved and loaded to and from files with Download ..., Upload ..., Download all scripts... and Upload all scripts .... An error in a script is shown with a message, and the operation of the form goes on.
