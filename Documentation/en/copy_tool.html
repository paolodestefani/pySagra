Copy tool

It adds to the current company the data of another company, for example to prepare a new festival starting from one already set up. The existing data stay; the copy can not be undone.

  • Copy from company: the company to copy from.
  • What to copy: Cash desks, Tables, Departments and Items. Inventory, Price lists and Settings are not available yet.

Items are linked to the department with the same description in the current company: to copy them the departments are needed, copied together or already there. The copy of the items covers their form, not variants, components and prices. Everything is copied together: when a part is not possible, for example because an item with the same description is already there, nothing is copied.
