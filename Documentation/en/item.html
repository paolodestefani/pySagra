Items

This form holds everything that is sold or that makes up what is sold: dishes and drinks, but also ingredients and components that never appear in the order entry window.

Item type

  • Item: a single product, for example a soft drink or a portion of chips.
  • Kit: a product made of several components and delivered as one thing, for example the dish sausages and polenta. In the order it stays one line; the inventory uses up its components instead.
  • Menu: a set of items or kits sold at one price. When the order is saved, the menu is replaced by its components, and each one goes to the copy of its own department.

The chosen type enables the tab it needs: Components for kits, Menu items for menus.

Main data

  • Item description: the name used in the program. It is required and can not be the same as the one of another item.
  • Customer description: the name the customer sees, on the customer copy and in web orders. It is required and unique; when it is empty, leaving the item description copies it from there.
  • Department: the department that prepares the item. It is required: it decides in which tab of the order entry window the button appears and on which department copy the item is printed.
  • Obsolete: the item is no longer used. It does not appear in the order entry window and in the lists, but it stays in the orders already made and in the statistics.

Sale in the order entry window

  • Salable: the item has a button in the order entry window. An ingredient that only makes up a kit, as the sausage to cook, is not salable.
  • Row and Column: the position of the button in the grid of the department. Two salable items of the same department can not take the same position. A salable item with no row and column has no button: a message says so when the order entry window opens.
  • Sorting: the order in which the item appears in the prints, within its department. It is optional: with no sorting the prints work all the same.
  • Normal background color and Normal text color: the colors of the button. Checking Salable proposes the ones set in the Settings; unchecking it clears them, because an item that is not sold has no button.

Row, column, sorting and colors can be changed only when the item is salable.

Controls

  • Inventory control
    • for an item: its stock is managed in the Inventory form and goes down with the orders.
    • for a kit or a menu: it turns on the availability check in the order entry window. The available quantity is not its own, it is computed from the components with inventory control; the ones without control do not limit it. When a menu contains a kit, check the control on the kit too.
  • Delivered control: the item appears in the Ordered delivered form. For a kit it counts the whole kit, for example how many dishes of sausages and polenta were delivered. For a menu it is not available: the menu is split into its components, and their controls count.
  • Kit part and Menu part: the item can be chosen among the components of a kit or a menu. The components of a kit are items; the ones of a menu can be items or kits.

Web orders

  • Web available: the item is sent to the web order server.
  • Web sorting: the order in which the item appears in the web order list, still within its department. It can differ from the Sorting of the prints.

Detail tabs

  • Variants, enabled by Has variants: the additions or changes the customer can ask for, each one with its Price delta. Copy variants from ... copies the variants of another item. In the order entry window the variant choice opens by itself or with the Variants button, depending on the Show variants automatically option of the Settings.
  • Components, for kits: the items that make up the kit and the quantity of each one.
  • Menu items, for menus: the items or kits of the menu and the quantity of each one.
  • Prices: the price of the item in each price list. The event uses the price list set in the Events form.

Deleting

An item can not be deleted when it is used in orders, when it has stock in the inventory or when it is a component of a kit or a menu: the program shows a message. In these cases check Obsolete instead.
