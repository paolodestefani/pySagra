Events

An event is a festival or a show with its dates. Every order belongs to the running event: the order entry window works only when an event includes the date and time of now.

  • Event description: the name of the event, required.
  • Start date and End date: the dates of the event, with the time. The end can not be before the start, and the dates can not overlap the ones of another event. A new event proposes now as start and seven days later, at 23:59, as end. When the event already has orders its dates can not be changed any more.
  • Price list: the price list with the prices of the event, see the Price lists form.
  • Event image: a PNG image, 640x480 pixels at most (a bigger one is resized). It is the background of the main window during the event and it can be used in the reports. Upload..., Download... and Delete load it from a file, save it to a file and remove it.

In the order reports and statistics the orders are split by event and, within the event, by day and day part: lunch goes from 8:00 to the dinner start set in the Settings; dinner from that hour to 8:00 of the day after.

Deleting

Deleting an event deletes all its data too: the orders with ordered/delivered and numbering, and the inventory. When the event has orders or inventory, the program asks a second time and lists what will be lost. There is no way to recover them, but from a backup of the database.
