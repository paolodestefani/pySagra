Order print settings

When an order is saved the program prints its copies: the customer copy, the cover copy and one copy for each department with items in the order. This form says, for each computer, how and where each copy is printed.

  • Computer name: the computer the setting is for; adding a row proposes the current one.
  • Print type: Customer, Cover or Department.
  • Department: for the Department type only, the department of the copy; empty for the other types.
  • Print copy: whether the copy is printed.
  • Print method: Driver (a printer of the operating system) or ESC/POS (a thermal printer driven directly, see the ESC/POS printers form).
  • Copies: how many copies to print.
  • Driver report and Driver printer: the report and the printer used with the Driver method.
  • Esc/Pos report and Esc/Pos printer: the report and the printer used with the ESC/POS method.

Each computer has one row for each print type and, for department copies, for each department. Each row can hold the parameters of both methods: when a printer breaks, changing the Print method switches to the other one with nothing to type again.

With no printer the copy goes to the preview. The Order print copy options of the Settings turn each copy type on or off for all the computers.

Copying the settings

Copy settings copies all the rows of a computer (Copy from) to a new computer (to): it is the quickest way to prepare a new cash desk like another one. When the target computer already has a setting of the same type and department, nothing is copied.
