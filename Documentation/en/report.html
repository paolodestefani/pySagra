Reports

The definitions of the reports used by the program, saved in the database. Every report has its print method (driver for the printers of the operating system, ESC/POS for the thermal printers), a class that says where it is used and a language.

  • Print Method, Code, Language/Country, Class and Description.
  • System report: a report of the program, which can not be changed nor deleted.
  • XML report definition: the text of the report, with the search (Find text) and the font choice.
  • Download ... and Upload ... save and load a report to and from a file; Download all ... and Upload all ... do the same with all the reports of a folder, for example after an update. At the end the program says how many reports it could not handle.

The print of a report is tried with the Print window.
