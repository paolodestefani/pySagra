Profiles

A profile is a set of rights on the functions of the program; every user gets a profile for each company.

  • Code and Description.
  • System profile: a profile of the program, which can not be changed nor deleted. To change it, make a copy with Duplicate.
  • Actions: for every function of the program, the Read, Write and Execute rights. Read opens the archives, write lets change them, execute is for the functions as the order entry or the tools.
  • Fill actions: adds the functions missing in the profile, with all the rights; Set all actions to gives all of them the same rights, to correct one by one afterwards.
