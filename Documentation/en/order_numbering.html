Order numbers

It shows, and lets correct, the last order number used. The program keeps a counter for each event, day and day part (lunch or dinner), and updates it by itself with every order.

  • Event, Event date and Day part: which turn the counter is for. There is one row for each turn.
  • Current value: the last number used; the next order takes the following one.

The Order number based on option of the Settings decides when the numbers start again from 1:

  • Event: the numbers go on for the whole event.
  • Day: they start again every day.
  • Day part: they start again at every lunch and every dinner.

The option can be changed during an event too. The same number can come again in different days or turns, but not twice in the same turn: lowering the current value below a number already used stops the next order from being saved. The filter chooses event, date and day part to see.
