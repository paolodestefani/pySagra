Order progress

It follows the preparation of the orders, department by department. Every department copy has a barcode: when the department delivers, the code is read and that part of the order becomes processed.

Order status

  • Acquired: no department has delivered yet.
  • In progress: some departments have delivered.
  • Processed: all the departments have delivered.

The status is computed by itself from the barcode readings.

Orders

The list shows the orders of the running event with the status of each department. They are filtered by status, with the Acquired, In progress and Processed checks, and by Date and Lunch or Dinner, or over the Whole event. Set whole order as Processed and Set whole order as Unprocessed change the status of all the departments of the chosen order.

Barcode reading

  • With the cursor in Barcode scan, the reader reads the code of the department copy: that part of the order becomes processed and appears in Barcode scanned. When it was already processed the program asks whether to read it again.
  • Set as unprocessed cancels the reading of the chosen row, for example one read by mistake.

The reading moves the quantities from ordered to delivered: it updates the Ordered delivered form and the unload of the Inventory.
