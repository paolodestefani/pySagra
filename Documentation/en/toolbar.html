Toolbars

The toolbars of the main window, with the buttons of the most used functions. As the menus they are organized as a tree, and every user gets a toolbar for each company.

  • Code and Description.
  • System toolbar: it can not be changed nor deleted.
  • The tree of the entries: bars, actions, separators and widgets, with description, sorting and action.

As for the menus, the entries used by a system toolbar too are read only, and the context menu of the tree saves the column layout.
