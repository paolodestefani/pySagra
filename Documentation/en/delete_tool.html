Delete tool

It deletes data of the current company in bulk, for example to start again from scratch or to remove the test data. It can not be undone: the data can be recovered only from a backup of the database.

In What to delete check the objects: Orders, Inventory, Events, Price lists, Items, Departments, Tables and Cash desks. They are deleted in this order, and all together: when one delete is not possible, nothing is deleted. For example the items used in orders can be deleted only by checking the orders too.

Deleting the events deletes their orders and their inventory too.
