Update Web Order Server

It sends to the web order server the data of the event: dates, tables, departments, web available items with prices and variants. The web site uses them to let the customer make the order, which is then shown at the cash desk with a QR code.

  • Event: the event to send; prices are the ones of its price list.
  • Server, port and encoding: the address of the FTP server, the port (usually 21) and the encoding of the names (usually utf-8).
  • User and Password: the FTP access.
  • File name: the path and name of the file on the server, as the FTP user sees them, for example event_data.xml.

The data are built and sent directly, with no file on the computer. When the server does not answer within 30 seconds the sending stops with a message. The parameters are saved after a successful sending.

The items with Web available are sent, in the order of the Web sorting.
