Users

The people that use the program. Everyone logs in with their own code and password.

  • Code and Description: required; the code is the name used to log in.
  • Language / Country: the language of the program and the number and date format of the user.
  • System user: a user of the program that can not be deleted.
  • Administrator: the user manages the program; for example they can customize the reports even without Can edit reports.
  • Can edit views, Can edit sort/filters, Can edit reports: can save for everybody the column layouts, the sortings and filters, and the report customizations.
  • Company / Profile / Menu / Toolbar: the companies the user can work in and, for each one, the profile with the rights, the menu and the toolbar.
  • User Image.

Security

  • Last used company, Last login and Last password change: read only.
  • Force password change: at the next login the user must choose a new password.
  • Set temporary password: gives a password, for example to a new user or to someone who forgot it; usually together with the forced change.
