Procedura di login

Per utilizzare pySagra è necessario far connettere il programma ad un database server PostgreSQL dove sia già presente una database applicativo di pySagra. Si vedano le istruzioni specifiche per l'installazione del server e del database applicativo.

Al primo avvio dell'applicazione vengono richiesti i parametri di connessione al server e la finestra si presenta come in figura:

I parametri richiesti per effettuare la connessione al database server sono:

  • Utente: inserire il codice utente applicativo. Il testo inserito è sensibile al maiuscolo/minuscolo ovvero "Paolo" e "paolo" sono interpretati some 2 utenti diversi.
  • Password: inserire la password associata all'utente selezionato. Può essere non obbligatoria in base a come è configurato il meccanismo di autenticazione degli utenti.
  • Server: inserire il nome del computer che svolge il ruolo di server di database. E' possibile inserire anche l'indirizzo ip del server (es. 192.168.1.1). Se il programma viene eseguito sullo stesso computer dove è in esecuzione il database server è possibile inserire il nome computer 'localhost' oppure l'ip 127.0.0.1
  • Porta: indicare la porta TCP da utilizzare per la connessione. Tipicamente nelle installazioni di PostgreSQL viene utilizzata la porta 5432, chiedere all'amministratore di rete nel caso si utilizzi una porta diversa
  • Database: indicare il nome del database al quale collegarsi
  • Utente DB: indicare il nome dell'utente di database per la login al database server e l'accesso al database applicativo. Questo è un utente del server PostgreSQL e non a nulla a che fare con l'utente applicativo richiesto sopra.
  • Password DB: indicare la password dell'utente di database indicato sopra.

Tramite il tasto Cancella le impostazioni locali è possibile azzerare eventuali impostazioni dell'applicazione memorizzate in locale nel PC, non nel database, che hanno generato problemi. Gli esempi tipici sono: nescoste per errore tutte le toolbar, modificata la dimensione della finestra che la rende invisibile, ecc.

Ci sono 2 utenti applicativi di sistema predefiniti e non modificabili:

  • system con password system
  • sistema con password sistema

Questi utenti sono amministratori ed hanno assegnato un menu ed un profilo che permette loro un accesso completo a tutte le funzionalità del programma. Si consiglia di modificarne la password al primo accesso ma non è obbligatorio farlo

Inoltre sono precaricati altri 2 utenti:

  • user con password user
  • utente con password utente

Essendo utenti normali si possono modificare ed anche cancellare. Sono utenti variamente limitati ma un qualunque amministratore può modificarne i permessi, profili e menu
