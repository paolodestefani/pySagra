Architettura dell'applicazione

Questo programma è stato sviluppato avendo in mente alcuni specifici obiettivi:

  • Realizzare un applicazione con interfaccia grafica e basata su un database server SQL
  • Realizzare un applicazione multiutente con architettura client/server
  • L'applicazione deve essere multipiattaforma e disponibile a basso/nessun costo a chiunque la richieda

Per la realizzazione di questo applicativo in base alle premesse precedenti sono stati scelti questi strumenti:

  • il linguaggio di programmazione Python nella versione 3.14
  • le librerie Qt in versione 6.x
  • il binding alle librerie Qt Qt for Python in versione 6.x
  • Il server di database PostgreSQL nella versione 18.x o successiva
  • Il connettore a PostgreSQL per Python Psycopg nella versione 3.3.x o successiva
  • il set di icone predefinito è oxygen ma sono disponibili anche altri iconpaks scaricati da Iconarchive
  • l'icona di pySagra fa parte del DelliOS System Icons set di dellustrations.com

Tutti gli strumenti elencati sono multipiattaforma e disponibili gratuitamente

Il programma è un'applicazione desktop scritta in python con PySide6 per gestire l'interfaccia grafica e le stampe e utilizza la libreria psycopg per accedere al database PostgreSQL. Il server di database deve essere installato precedentemente ed avere un database applicativo di pySagra già installato.

Ogni client accede al database creando un'unica connessione che rimane attiva fino alla chiusura del programma. Ogni client dialoga direttamente con il database, non ci sono livelli software intermedi. Come conseguenza il controllo di concorrenza viene gestito direttamente dal server PostgreSQL.

Per le stampe è stato realizzato un motore di reportistica basato sulle librerie grafiche Qt che utilizza la gestione delle stampanti del sistema operativo, i driver delle stampanti. A questo è stato affiancato in un secondo momento un motore di reportistica per stampare direttamente su dispositivi Esc/Pos che sono le stampanti termiche più comuni per realizzare scontrini ed etichette. Entrambi i metodi di stampa permettono di generare anche anteprime a video ed export in formato PDF.

E' gestito un elenco degli utenti applicativi e relative password per l'accesso alla procedura. Gli utenti possono avere accesso solo a specifiche aziende e per ogni azienda può essere associato un profilo diverso. Tramite i profili si definiscono i permessi di accesso alle singole funzioni del programma.
