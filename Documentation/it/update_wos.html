Aggiorna il Web Order Server

Invia al server degli ordini web i dati dell'evento: date, tavoli, reparti, articoli disponibili sul web con prezzi e varianti. Il sito li usa per far comporre l'ordine al cliente, che poi lo presenta in cassa con un codice QR.

  • Evento: l'evento da inviare; i prezzi sono quelli del suo listino.
  • Server, porta e codifica: l'indirizzo del server FTP, la porta (di solito 21) e la codifica dei nomi (di solito utf-8).
  • Utente e Password: l'accesso FTP.
  • Nome file: il percorso e il nome del file sul server, come li vede l'utente FTP, per esempio event_data.xml.

I dati vengono preparati e inviati direttamente, senza file sul computer. Se il server non risponde entro 30 secondi l'invio si interrompe con un messaggio. I parametri vengono salvati dopo un invio riuscito.

Partecipano gli articoli con Disponibile sul web, nell'ordine dell'Ordinamento web.
